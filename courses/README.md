# 内置课程

默认课程：[AI 带货视频实战工作坊](ai-commerce-workshop/brief.md)。用户只说「这门课、现有课程、继续做」且没有其他上下文时，先使用此课程；给了另一门课的简介则以新简介为准，不混入默认课程事实。

本目录保存用户获准共享的课程简介、脱敏课纲、工具说明及已认可的宣传要求。私人聊天原文、学员身份、凭证和发送记录仍留本地。

课程更新时同步维护 brief.md 与 profile.json；模块变化再更新 outline.md，工具变化更新 tools.md。将可复用的编辑反馈提炼进简介或写作参考，同时保留来源/日期与版本说明。助理更新仓库后即可得到这些新信息，无需另找背景包。
