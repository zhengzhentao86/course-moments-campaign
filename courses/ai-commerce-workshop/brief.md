# AI 带货视频实战工作坊

资料版本：2026-09-30。默认课程 ID：`ai-commerce-workshop`。这是已经获准随技能分发的课程简介，助理可以据此直接写作，不需要用户再补一份背景表。

## 定位与适合人群

这是一门 AI 与电商业务结合的线下实战课。生成图片、视频是基础能力；课程重点是将分析、内容策略、视频制作、素材迭代和团队分工接进已有业务，帮助卖家探索增长和改进工作方法。不得把课程目标写成保证销量或确定的收益。

适合已完成从 0 到 1、有电商基本盘的卖家、老板及其内容团队。学员最好能带一款实际商品、已有素材和一个真实业务问题来练。不适合没有做过电商的小白，或单纯寻找副业的人。

## 8 大模块及衔接

| 模块（保留原课纲名称） | 解决的业务问题 | 学习与练习如何衔接 |
|---|---|---|
| 1. AI时代下的内容电商产生了什么样的变化 | 老板不清楚 AI 能进入哪段现有工作 | 认识能力边界与品类场景，进行团队落地阶段自查，为后续选方向打基础 |
| 2. 拆竞对与素材复盘（上、下合为一个模块） | 只盯一条爆款、抄到表面，缺少系统判断 | 批量看行业素材、标签与可视化看板，结合已有素材和数据找待优化方向 |
| 3. 制定内容策略，确定高转化的内容方向 | 商品卖点很多，却不知道讲给谁、先测什么 | 12大维度挖卖点，8大技巧翻译买点，结合人群和场景排序，现场练内容测试矩阵 |
| 4. AI视频实操 | 想法和脚本难以稳定变成可用画面 | 练提示词五要素、参考图与产品细节，从模糊想法到完整带货视频的制作过程 |
| 5. AI视频的高阶玩法 | 单条能生成，换人物、场景或口播就混乱 | 学剧情、KOC、声音、结构化提示词和变量替换，理解素材裂变的方法 |
| 6. 如何做出能爆量的AI视频？ | 有少量素材，却没有可持续选择的内容形式 | 六类母版为痛点、种草、场景、剧情、证据、机制；结合策略选择形式与组织结构 |
| 7. 如何用AI做出高点击、高转化画面？ | 参数和卖点说了很多，顾客看不见价值 | 练开头、痛点特写、效果对比、反差和卖点可视化；高成本场景与真实产品细节合理分工 |
| 8. AI时代的内容组织升级 | 老板或个别人会用，团队仍无法接着做 | 明确老板、管理层、执行人员的人机分工，从一个业务问题验证，沉淀团队方法 |

模块 2 的上午和下午是上下两段，不得拆成第 9 个模块。「如何做出能爆量」「高转化」是原课纲标题，不是对每位学员结果的保证。

可以把这条工作链用于海报：

`看清行业与自身卡点 → 复盘参考与素材 → 确定人群/买点/场景 → 做视频 → 变体与母版 → 画面表达 → 团队继续测试和复盘`

这条链是课纲的宣传归纳，不替换上面的正式模块目录。

## 最值得强调的课程价值

- 把实际商品与问题带进课堂，让前一个模块的分析为后面的制作提供依据。
- 现场跟着做，不停留在观看工具演示；文案应讲具体练习，而非反复喊「实操」。
- 工具、模板和手册配套提供，让学员回去仍有起点。第三方平台会员、算力和永久服务不在已核实权益中。
- 课程面向有业务的人，重点是判断和使用方法：做什么、为什么做、如何做、谁来接着做。
- AI 是工作能力的一部分。素材是否有效需要实际使用和复盘，不许把生成成功写成带货成功。
