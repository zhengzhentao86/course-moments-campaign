# 写作与系列编排

## 默认声音

像一个理解业务、亲自教课的人，向熟悉的同行讲一件具体的事。自然、直接、有细节，不居高临下。可以用「我/我们」，但共用发布稿不冒充只有某讲师才有的经历；没有真实依据不写「昨天有位老板找我」「我服务过上百家」。

常见展开：具体工作卡点 → 卡在什么环节 → 课上怎样处理 → 一个例子/练习 → 回去怎样继续用 → 自然邀请。各条调整开头、节奏和顺序，不逐句复刻公式。先写完整再删掉套话；不靠拉长空话凑字数。

少用「赋能、降本增效、闭环、颠覆、超级干货、抢占红利、爆单、不会就被淘汰」；有实际流程再用普通话说明。不要连续「不是X，而是Y」、碎片排比或满屏感叹号。别只列课程内容，也别为了高级感发明抽象术语。

好表达应回答：哪一类人，在哪个工作场景遇到什么问题，课上怎么练，产物怎么接回工作。课程帮助改善的是哪一个可执行环节？不是未经验证的销量承诺。

## 四种模式

### 课程系列

20 条可参考分布（按实际素材调整，非强制配额）：5 条具体业务卡点；4 条模块衔接；3 条现场练习；3 条工具和模板；2 条团队使用；2 条有证据反馈；1 条适配判断。没有可靠证言就换为具体场景，不编满配额。

单条即使独立转发，也应知道在讲什么课程价值；不要每条都列完整课纲。相邻两条开头、主旨、图形和 CTA 至少有实质变化。

### 工具篇

按「谁在什么工作里卡住 → 工具需要哪些真实输入 → 辅助完成什么 → 课程哪一环教会判断 → 输出交给谁继续做」写。可以一工具一条，也可按任务组合 2—3 个有关联的工具。

例如「卖点—买点转换器」不只写送智能体，而是讲产品参数怎样结合人群场景形成购买理由，再变成镜头任务。明确示例是表达思路，不冒充真实客户收益。工具确实提供给学员才能写赠送，不能暗示生成平台会员、算力、永久更新或所有商业授权也赠送。

### 学员反馈篇

保留具体任务、变化、边界：之前怎么做、课上哪一步有帮助、现在能做什么、仍须自己验证什么。保留有价值的正向事实，删除身份隐私。轻度润色只改语病和冗余。

- 同一人的转述：「一位服装类目的同学提到……」；高度改写不加引号冒充逐字引用。
- 多人归纳：「几位不同类目的同学，反馈里有一个共同点……」后列各自真实事实。
- 一人只会拆解、另一人会改脚本，不能拼成「某位同学掌握完整增长系统」。
- 不把「满意、好用、终于理解」升级为「转化翻倍」。关键限制会改变含义时必须保留。
- 证据核验和大部分限制说明留在内部记录。公开稿没有声称销量或投放效果时，不必反复插入「尚无数据、未经验证、不能证明」等审计语言；必要边界可以集中一处自然交代。正向内容仍应写得有温度，不能为谨慎把朋友圈写成审查报告。

### 倒计时篇

D10 业务价值；D9 适合谁；D8 系统路径；D7 决策/分析；D6 工具；D5 实操；D4 内容复用；D3 团队落地；D2 带什么来；D1 开课前提醒。按真实课程改写，不把这份路线当固定课纲。

倒计时突出事实上的临近，每天贡献一个新理由。没有真实报名截止或席位数据，不写「最后名额、即将涨价、报满就停」。D1 不虚构住宿、群通知、签到地点。开课时间未知时可先写非日期依赖部分，日历和最终海报需补齐。

## 内部审稿

对每条用 0/1/2 检查受众具体、问题具体、课纲对应、动作/产物明确、自然表达、主题独立；任一项 0 先修。事实和证言不合格直接退回，不靠总分抵消。此评分仅供编辑，不能证明真实转化率。
