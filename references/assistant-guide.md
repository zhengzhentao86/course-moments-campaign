# 助理上手

## 安装

将完整 `course-moments-campaign` 文件夹放到你的 AI 工具支持的 skills 目录。Codex 常用 `~/.codex/skills/`；其他支持 SKILL.md 的工具按其技能安装入口导入，不能只复制 SKILL.md 而漏掉参考图和资源。新开任务并查看技能列表；若平台未自动发现，直接提供本技能 SKILL.md 路径读取使用。

本技能本体不含账号、密码、客户私聊或收件人。生成图片需要当前工具具备内置图像生成能力；飞书链接和发送需要在你的机器上安装并登录 lark-cli，以及相应访问权限。脚本需要 Python 3.9+，无第三方包。缺少图片能力时可以写文案和提示词，但不能算图文全套完成。

## 从 GitHub 安装或更新

公开仓库：`zhengzhentao86/course-moments-campaign`。下载与克隆不需要 GitHub 登录或邀请。下面命令适用于已安装 Git、目标目录尚不存在的首次安装：

```bash
git clone https://github.com/zhengzhentao86/course-moments-campaign.git ~/.codex/skills/course-moments-campaign
```

已经由 Git 克隆安装的，用 `git -C ~/.codex/skills/course-moments-campaign pull --ff-only` 更新；有本地修改先检查并保留，不强制覆盖。目录存在但并非 Git 仓库时，让 AI 备份并合并安装，不直接重复克隆。也可从仓库 Release 下载压缩包完整安装。

## 直接这样说

- 「使用 $course-moments-campaign，用内置的现有课程简介，再做 20 组朋友圈文案和海报。」
- 「使用 $course-moments-campaign。这是新课程简介：……先给我 20 条选题方案，确认后再做图文。」
- 「使用 $course-moments-campaign。按这份简介直接做 20 组朋友圈文案和海报，沿用清爽画风。」
- 「这一期仍是同一门课，日期改成……。做 10 条工具篇，一条文案配一张海报，通过飞书发给我。」
- 「从开课前 10 天到前 1 天，每天一组图文，附准确发布日期。」
- 「这条太像广告，结合老板的具体工作写长一点；这张图保留绿色，删掉多余装饰。之后这门课也按这个方向。」
- 「这几段是学员反馈，用能核实的正向内容，给我补 5 条；多个学员请写成归纳。」

有新简介就先给简介，不用额外填表。AI 应主动提取资料、维护课程档案，只问确实缺失且影响执行的事实。

## 换电脑、换助理、换课程

技能包已携带现有课程简介、完整课纲快照、工具说明、宣传偏好、40条已用选题和3张已认可样图，助理可以直接用。运行期间的私人证据和发送记录保存在项目目录，不随仓库分发。更新本技能并拉取最新版本，就能获取新的共享课程资料；不共享私人原文和登录信息。首次发送须使用助理自己的获授权飞书身份，定位当前用户指定的收件人。

换课程会新建 course_id，保留通用画风、表达习惯；旧课程的受众、模块数量、日期和结果不能自动沿用。只改变一期日期时，应复核该期课纲/权益是否也更新，不必重问所有背景。

## 怎样持续变好

把意见直接说给 AI：哪里不对、想强调什么、哪条好。AI 负责记录、修订并留例子。要求迭代技能时，将可共享的规则和本课资料更新到 courses/ 并按授权发布新版；助理拉取新版就能继续使用。私人原文不入库，技能不会自动监听微信。
